# ai-happy-01 — for you

[![make.fun · ai-happy-01](https://make.fun/badge/ai-happy-01.svg)](https://make.fun/bounty/ai-happy-01)

An old fisherman rests his closed eyes and chin on the head of a scruffy orange
harbour cat. Warm lantern light softens the quiet moment against the cold blue dusk;
the image holds a gentle, quiet warmth between two companions. The entry program
copies `entry.png` (1024x1024, one PNG) to the grader's output path.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The picture is drawn as vector shapes, not sampled from a model: the palette, the
glow, the rim light and the little tag are all code. License: MIT.
